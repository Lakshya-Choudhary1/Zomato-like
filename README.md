# 🍔 Food Delivery Platform (MERN Stack)

A full-stack food delivery application built using the MERN stack with authentication, food partner management, image/video uploads, and dynamic user feeds.

## 🚀 Live Demo

https://zomato-like-d4bh.onrender.com

---

## ✨ Features

### 👤 User Features
- User registration & login
- Secure authentication using JWT
- Browse food items
- Food video feed
- User profile management
- Dynamic food recommendations

### 🍽️ Food Partner Features
- Food partner registration/login
- Partner authentication middleware
- Create food items
- Upload food images/videos
- Manage food partner profile
- Fetch real-time partner data

### 🔐 Authentication
- JWT based authentication
- Protected routes
- Separate user & food partner authorization
- Auth middleware

### ☁️ Media Upload
- Image/video upload support
- Integrated cloud storage using ImageKit
